# estefmej.github.io

Sitio personal de Estefanny Mejía, publicado con GitHub Pages.

- `index.html`: página principal.
- `proyectos/`: una página por proyecto.
- `demo/`: dashboards interactivos (agua segura y el fuego y el agua).
- `data/CV_Estefanny_Mejia.pdf`: CV (compilado desde `data/CV_Estefanny_Mejia.tex`, en LaTeX).
- `images/`: figuras de los proyectos.
- `videos/`: reels (la voz es generada con IA a partir de la voz de la autora).

Diseño basado en el [sitio de Jon Barron](https://github.com/jonbarron/jonbarron_website).
